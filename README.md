# 🚀 Fundamental Booster



## 📌 About The Project

**Fundamental Booster** is an interactive Personal Data Collector application built using Python.

The program collects personal information from the user, processes the data, performs basic calculations, and displays a formatted summary.

This project demonstrates my understanding of Python fundamentals, including variables, data types, operators, type casting, and built-in functions.

## 🎯 Project Objectives

- 📥 Collect personal information using `input()`.
- 🖥️ Display information using `print()`.
- 🔢 Understand Python data types and variables.
- ➕ Perform calculations using arithmetic operators.
- 🔄 Convert values using type casting.
- 🧠 Explore `type()` and `id()` functions.
- ✨ Format output using f-strings.
- 📝 Generate a personalized information summary.

## ✨ Features

| Feature | Description |
|---|---|
| 👤 Personal Information | Collects name, age, height, and favourite number |
| 🔢 Data Types | Demonstrates `str`, `int`, and `float` |
| ➕ Calculations | Calculates an approximate birth year |
| 🔄 Type Conversion | Converts values between different data types |
| 🧠 Type Inspection | Identifies data types using `type()` |
| 💾 Memory Inspection | Displays object identity using `id()` |
| 🎨 Formatted Output | Uses f-strings for readable output |
| 💬 Interactive Console | Guides users through the program |

## ⚙️ Installation & Setup

Follow these steps to run the project on your computer.

### 1️⃣ Install Python

Install Python 3 if it is not already installed.

### 2️⃣ Clone the Repository

```bash
git clone <your-repository-url>
```

Replace `<your-repository-url>` with your actual GitHub repository URL.

### 3️⃣ Navigate to the Project Folder

```bash
cd Fundamental-Booster
```

### 4️⃣ Run the Application

```bash
python main.py
```

**Alternative command for Windows:**

```bash
py main.py
```
